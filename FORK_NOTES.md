# TrafficMonitorPlugins-MusicPlayer2Lyric

This is a personal fork of TrafficMonitorPlugins.

It adds a `MusicPlayer2Lyric` plugin that reads lyric state from the patched MusicPlayer2 shared-memory IPC and displays it in TrafficMonitor.

This plugin is intended to be used together with:

```text
https://github.com/ImKani/MusicPlayer2-TaskbarLyric
```

Upstream:

```text
https://github.com/zhongyang219/TrafficMonitorPlugins
```

Integration package:

```text
https://github.com/ImKani/MusicPlayer2TaskbarLyric
```
